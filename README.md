# film heap local companion

Your films. Your computer. Your people.

Download the Windows companion from [film heap](https://torrent-streaming-tan.vercel.app/?view=friends) or this repository's Releases. Open the single executable, then connect it from the website with the code shown in the companion window.

Windows 10/11 x64. The companion includes its runtime and playback tools. Keep your computer awake and your film drive connected while watching or hosting. Internet screenings require a secure hosting connection configured on your computer.

This public repository distributes approved downloads only. The application source repository is private. No personal libraries, films, databases, account sessions or filled credentials are included in the download.

The current preview is unsigned. Windows may show an unknown publisher notice. Do not disable Windows security protections. The release manifest provides the exact SHA-256 fingerprint and file size; `Get-FileHash .\film-heap-companion.exe -Algorithm SHA256` lets you compare your download.
